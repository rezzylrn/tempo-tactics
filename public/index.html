      How to win

      Hold the gold center tile at the end of a full round to earn a beacon point — first to 3 wins. Or destroy every rival unit. Matches end after 60 turns, decided on points, then units, then HP.

      Tempo Tactics — original game built for the Taskmarket multiplayer strategy bounty. Rules, API docs and the sample bot are in the public repo.
